# 2026-11-16 后续补记：ACP 技能里的交接用法

## 调整

- `acp-service` 技能写明交接从主会话的 `a2a-gateway` 或 `acp-service a2a invoke` 调用。提议和接受都不派单；下一张任务要另调 `execution_submit` 并带 `handoffId`。
- 写明执行中的 ACP 会话没有 handoff 工具，也没有 `acp-service handoff` 子命令。`acp-service a2a --help` 列出 `handoff_*` 方法。

# 2026-11-16 后续补记：交接与三种目录

## 新增

- 账本可以记录交接。`handoff_propose` 只提议把当前轮次已记录的产物交给另一个执行目标；`handoff_decide` 接受或拒绝。接受不会派下一单，下一单要另调 `execution_submit` 并带上 `handoffId`。
- `handoff_offer` 登记一条约定。验收通过或任务单关闭、且只有一条不要求人确认的约定成立时，账本记下已接受的交接，仍不派单。多条同时成立时不挑选。
- 工作台投影只画已经提议、接受或走成的交接。尚未发生的约定写在当前任务的 `legalNext` 上，不画成路径。
- 同一件事的目录分开。任务目录仍是 `<cwd>/.1agents/jobs/<jobId>/`。角色公开目录是 `<cwd>/.1agents/roles/<roleId>/published/`。`handoff_space` 把一个已有宿主目录登记为该 `caseId` 的共享产物空间；清单里的文件可以落在任务目录或这块空间，不能落在角色目录。

## 验证

- 交接规则、工作台投影、目录划分和共享产物校验的单测已通过。未做端到端派单实测。

# 2026-11-16 后续补记：A2A 工作台迁移到 dsh-a2a

## 修复

- 桌面版 A2A 工作台空白的真正根因不是 3080 端口：面板由 `@1agents/acp-service` 的客户端代码注册，其 iframe 使用**相对路径** `src="/workbench/ui/"`，因此请求发给 DSH Web GUI 自身的源；而该路由在 ACP 插件中位于 `if (input.a2a)` 分支内，Desktop 从未提供 `a2a` 字段，路由未注册，页面 404。此前配置的 3080 独立服务与该 iframe 无关。
- 迁移后由 `@1agents/dsh-a2a` 独占工作台，并在 `apply` 中声明 `inject = ['webServer', 'connection']`。缺少该声明时 Cordis 可能在服务就绪前应用本 bundle，是面板空白的直接成因。

## 调整

- `@1agents/dsh-a2a` 新增宿主侧工作台 `src/host-workbench.js`：在宿主 `webServer` 以 `prefix` 注册 `/workbench/ui`，提供页面与静态资源，并以 `frame-ancestors 'self'` 允许侧栏 iframe 嵌入；页面 API 复用宿主浏览器登录（不再有第二套工作台令牌），网关 bearer token 与 `pageRelaySecret` 始终留在服务端。
- `@1agents/dsh-a2a` 新增客户端侧栏面板 `src/client.js`（`dsh.client.platform: web`，`dist/client.js` 经 `window.__ModuleLoader__` 包装），承载“A2A 工作台”入口与 `1agents:open-session` 消息处理。
- `apply` 支持 `port: false`：只提供宿主页面而不启动独立监听，便于仅嵌入工作台的 profile 使用。
- `@1agents/acp-service` 移除工作台面板、宿主 `/workbench/ui` 路由与 `src/workbench.ts`，不再需要 `a2a` 字段即可避免空白；其职责收敛为 ACP 执行。
- 版本：`@1agents/dsh-a2a` 0.2.1，`@1agents/acp-service` 0.10.6，均已发布到公开 npm。Desktop profile 依赖同步升级，并撤掉上一条补记中为 ACP 添加的临时 `a2a` 配置。

## 验证

- `@1agents/dsh-a2a` 19 项测试通过，其中新增 7 项宿主工作台测试（页面可被 iframe 嵌入、宿主登录免二次令牌、拒绝 agent 与跨站写入、凭据不外泄、headless 任务不可接管、process-requests 拒绝、宿主准入）。
- `@1agents/acp-service` 41 项插件测试与 472 项 service 测试全部通过；清理重建后 `vendor/dsh` 中已无 `workbench.*`，客户端产物无面板引用。
- 模拟宿主调用 `apply` 后确认注册 `prefix /workbench/ui`，实际请求 `/workbench/ui/`、`/workbench/ui/app.js`、`/workbench/ui/api/session` 均返回 200，`Content-Security-Policy` 为 `frame-ancestors 'self'`。
- 待办：需重启 Electron 应用加载 0.2.1/0.10.6，再在桌面端确认工作台不再空白。
