# 2026-10-28

- 工作台令牌改为可选：网关配置不写 `workbench.token` 时，`/workbench/ui/` 免登录、不显示退出登录，`/workbench/*` 接口不校验 bearer；页面写操作仍要求同源浏览器，带 Authorization 或代理头的请求仍不能走页面接口。DSH 插件的 `a2a.workbench.token` 同样可省略，省略时不带 bearer。生产环境改用账号体系。
- 「工具未获批准」只看每个工具最近一次审批：审批过期后 Agent 重试同一命令、人在页面允许了，任务按已完成显示；其他工具仍未批准时照旧标出。线上核对时发现（任务 0d0feece：第一次过期，重试被允许，结果 Python 3.12.8）。
- 工具审批可以附拒绝理由，并分成「拒绝这次调用」和「拒绝并停止任务」。后者在拒绝后取消整个任务，理由写进取消记录和发给发起会话的通知，Grok 不再换方式重试。ACP 权限答复没有理由字段，理由不会交给 Grok 本身。
- 审批期限可配置：网关 `workbench.requestTimeoutMinutes`（默认 5，最多 1440）；ACP 桥接的提问、计划和工具审批期限由 `ACP_INTERACTION_TIMEOUT_MS` 设置（默认 5 分钟），桥接期限不能短于网关期限。
- 新的过程请求可弹 macOS 通知：网关 `workbench.desktopNotifications: true` 时开启，默认关闭。
