# 2026-11-25

## 新增

- 新增：`SessionDelivery` 与 DSH 宿主投递（`packages/service/src/a2a/session-hosts.ts`、`packages/service/src/a2a/session-delivery.ts`）支持可选投递模式 `mode?: "queue" | "steer"`（默认仍为 `"queue"`）。投递到 DSH 宿主 `/api/session/prompt` 时透传 `mode`，投递到 Codex 宿主保持 `codex queue` 语义；同一 `messageId` 切换 `mode` 视为幂等冲突，并发入队会触发 `reconcile()` 立即补泵而不必等待下一轮轮询。
- 新增：A2A 网关 `openProcessRequest`（`packages/service/src/a2a/gateway.ts`、`packages/service/src/a2a/notices.ts`）在子任务首次登记过程请求（工具权限 `permission`、计划 `plan`、提问 `question`）时，若发起方 `originSessionId` 已通过 `session_bind` 绑定且未关闭 `workbench.notifyOriginOnProcessRequest`（默认 `true`），立即以 `mode: "steer"` 写入保留命名空间 `process-request:<requestId>` 的 `<system-reminder>` 提醒并异步触发派发；请求被回答或过期后自动确认对应投递记录，避免过期提醒重复唤醒。
- 新增：`execution_process_answer` 放开可选 `answers` 字段（沿用 `processRequestAnswerSchema.shape.answers` 校验），便于发起方智能体按需答复 `question` 类过程请求；`session_send` 同步保留 `process-request:` 命名空间。
- 新增（方案 B 消息块展示优化）：
  - `packages/dsh-plugin/src/session-notice.ts` 与 `packages/dsh-plugin/src/index.ts` 新增 `POST /api/1agents-acp/session/deliver` 路由，以 DSH 原生 `ContextFormed`（`source: { kind: "1agents-acp", form: "notice", summary, rpcId }` 或 `form: "relay"`）向目标会话执行幂等 `agent.steer()` / `agent.followup()` 并刷盘，在 DSH 对话流中渲染为可折叠的单行系统通知条而非人类聊天气泡；
  - `packages/dsh-plugin/src/adapter.ts` 放行 `source.kind === "1agents-acp"` 的消息，确保 DSH 托管的外部 ACP 会话（`oneagents-acp-*`）同样接收该类通知；
  - `packages/service/src/a2a/session-hosts.ts`、`session-delivery.ts`、`notices.ts`、`gateway.ts` 新增 `notice?: { form: "notice", summary } | { form: "relay" }`、`formatProcessRequestSummary` 与 `formatNoticeSummary`（120 字上限）；统一将过程审批（`process-request:`，`mode: "steer"`）、A2A 任务结果通知（`a2a-notice:`，`mode: "queue"`）与领域交付通知（`execution-notice:`，`mode: "queue"`）均按 `form: "notice"` 优先投递到 `/api/1agents-acp/session/deliver`，仅当旧版宿主返回非 RPC 的 HTTP 404 时自动降级回 `/api/session/prompt`。
- 新增（轻量 A2A 审批/任务单 MCP Server 与跳过 `search → inspect` 直调契约）：
  - `packages/service/src/a2a/gateway.ts` 新增只读聚合方法 `execution_pending_approvals`，支持跨任务（或按 `originSessionId`/`jobId`）列出全部待审批过程请求、待裁决任务单改进提议与活跃任务单；
  - 新增 `packages/service/src/a2a/approval-mcp.ts` 与 CLI 入口 `packages/service/bin/mcp.ts`（`acp-service mcp [--url] [--agent] [--session]`），以零额外依赖的 stdio JSON-RPC 2.0 MCP Server 代理本机 `a2a-gateway`，直出 6 个一级工具（`a2a_pending_approvals`、`a2a_process_requests`、`a2a_process_answer`、`a2a_ticket_get`、`a2a_ticket_proposal_decide`、`a2a_execution_review`），自动补齐幂等 `clientRequestId` 并强制以 `kind: "coach"` 落盘（不冒充 `kind: "person"`，不触碰 `PAGE_ONLY_ROUTES`）；
  - 更新 `packages/service/src/a2a/notices.ts` 的 `<system-reminder>` 提醒正文，内联 `mcp-a2a-approval.a2a_process_answer` 精确 `dreammate_invoke` 调用模板，使被 `steer` 唤醒的发起方智能体可直接跳过 `dreammate_search_tools` / `dreammate_inspect` 一步审批；
  - 新增随包技能参考 [packages/service/skills/acp-service/references/approval-mcp.md](../packages/service/skills/acp-service/references/approval-mcp.md) 并更新 [packages/service/skills/acp-service/SKILL.md](../packages/service/skills/acp-service/SKILL.md) 与 [docs/session-delivery.md](../docs/session-delivery.md)，提供完整 `mcp-a2a-approval` 直调契约表与 DreamMate 注册命令。
