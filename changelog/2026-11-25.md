## 修复

- 修复：DSH 的 ACP 预设会话里，外部 Agent 的工具调用（Bash / Read / Edit 等）在聊天区完全不显示，只剩正文与「思考」。根因是 `2026-11-23` 的 `de6163c7`（"let DeepSeek Harness render the ACP transcript"）删除了插件侧的自绘（`tool-conversation.js` + `transcript-view.js`），改为"由 DSH 自己渲染"；但 DSH 的聊天区只画 `tool/call` 会话事件产生的原生工具卡，并不认识插件写在空文本块上的 `acpTool` 元数据（整个 DSH 安装包中 `acpTool` / `acpTranscript` 出现次数为 0），于是工具快照落成空文本块、渲染为空白。数据本身从未丢失：截图对应的会话 `session-204d615e-1342-4e5f-a9f8-959e821aed6e` 的持久化日志里有 13 个带 `title` / `status` / `kind` / `rawInput` 的 `acpTool` 块。
- 修复：工具卡不再整组排在一轮之前，而是按各自空文本块的 stream index 插回思考/正文中间；同一轮的思考、工具、回答按 Agent 实际产生顺序展示。DSH 会把一条助手消息拆成「思考」和「回答」两个过程行，工具卡按其前一条正文块归入对应过程行，因此跟随思考的调用留在思考组，跟随回答的调用留在回答组；没有正文的轮次才单独出一行。
