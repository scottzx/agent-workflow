## 修复

- 修复 `packages/service/src/rsi/outline-run.ts` 在同一秒内连续启动多次非 `resume` 运行时工作目录 `${caseId}-${stamp}` 与 `clientRequestId` 碰撞的问题：改用原子 `mkdir` 分配唯一目录后缀（`-2`、`-3`…）并同步去重 `clientRequestId`，避免后一次运行复用前一次遗留的 `run-state.json` 导致 `l1_crosscheck` 命中缓存而跳过 `ticket_checks`；同时补充 `applied.cached` 下任务单仍处 `drafting`/`ready_for_review` 时的兜底校验，并在 `packages/service/test/rsi-outline-run.test.ts` 新增固定时钟同秒回归用例。

- L3 打分不再把 `**无。**`、`- 无阻塞项` 这类空 MUST 当成缺陷，代码块里的 `## MUST` / `### M1` 也不再变成幻影条目。`VERDICT` 只取标题行，否则只取该节第一条非空行；后文里的 `L1 gate: PASS` 不参与结论。
- 一条 MUST 最多核销一条 `requiredDefect`。`continue-misses-delivery-mode` 必须出现继承或 `deliveryMode` 缺失，不能只写 `execution_continue`。
- `checks/run-l3-eval.mjs` 在切到 `packages/service` 之前，按调用方当前目录把 `--role-dir`、`--repo`、`--results`（含 `--flag=value`）解析成绝对路径。
- `rsi eval-cr` 对不存在的 `--results` 和非法 JSON 分开报错。`findRepoRoot` 拒绝符号链接 `.git`。基准提交 SHA 只接受小写十六进制。
- `parseMarkdownCrReport` 不再只认 `#` 标题。独立的 `**MUST**`、`__MUST__`、`**2. MUST**`、`**MUST（阻塞缺陷）**`、`**MUST:**`、`MUST:` / `MUST：` 以及冒号后的同行正文都会打开 MUST 节；`**SHOULD**`、`**VERIFIED_CHECKS**`、`总结` / `结论` 和同级或更高级 `#` 标题会结束当前节，避免后续段落被吞进 MUST。没有 MUST 节头时，顶格 `### M1`、`- **[M1]**`、`**[M1]**` 仍算阻塞项，`PASS` 不能再静默变成 0 误报。代码块里的伪节头、以及正文里的“无 MUST / 0 MUST”不产生幻影条目。`.1agents/roles/pr-delivery/QA.md` 增补 L3 可机审的输出格式契约，不改 7 条红线。
