MUST**`、`**MUST（阻塞缺陷）**`、`**MUST:**`、`MUST:` / `MUST：` 以及冒号后的同行正文都会打开 MUST 节；`**SHOULD**`、`**VERIFIED_CHECKS**`、`总结` / `结论` 和同级或更高级 `#` 标题会结束当前节，避免后续段落被吞进 MUST。没有 MUST 节头时，顶格 `### M1`、`- **[M1]**`、`**[M1]**` 仍算阻塞项，`PASS` 不能再静默变成 0 误报。代码块里的伪节头、以及正文里的“无 MUST / 0 MUST”不产生幻影条目。`.1agents/roles/pr-delivery/QA.md` 增补 L3 可机审的输出格式契约，不改 7 条红线。

- 插件卸载改为单个 Cordis effect 内的确定顺序：先卸路由、工具和预设并清空 `review.host` / `oneagentsA2aHost.current`，再 `closeA2A`（含 A2A `DirectoryLease`）、`nativeSessions.dispose()`、`adapter.dispose()`，然后关闭诊断 `DirectoryLease`，最后释放服务租约。`serviceMode: external` 与 `launchd` 的释放仍是空操作，热重载不会杀掉外部或 launchd 常驻的 `acp-service`。`mountDshA2A` 在这条链上不再另挂一个并行 effect。
- `packages/dsh-a2a/test/runtime.test.mjs` 的用例不再依赖本机全局的 ACP 容量状态。夹具把 `ACP_CAPACITY_DIRECTORY` 指向用例自己的临时目录并在结束时还原。改前，本机正在运行的 `acp-service` 留下的容量租约会让 `CapacityQueue` 的入队事务耗尽自身 5 秒期限并抛出没有错误码的通用失败，任务只报 `ACP execution failed.`、`validation` 停在 `not-requested`，`PRESET_UNSUPPORTED` / `MODEL_SELECTION_UNSUPPORTED` 被掩盖；用例的 1 秒轮询预算因此看不到预期的终态。改后入队立即拿到槽位，校验按预期失败。同一用例的 A2A 服务改为在用例体内关闭，早于夹具删除状态目录，避免仍在飞行中的任务写进已被删除的目录。
- 插件启动失败与正常卸载收口为同一条幂等释放链 `teardown()`（`packages/dsh-plugin/src/index.ts`）。改前失败回滚只清理 `stops`、服务租约与诊断租约，漏掉 `closeA2A`、`nativeSessions.dispose()`、`adapter.dispose()`，也没有复位 `review.host` 与 `oneagentsA2aHost.current`。当 `ctx.effect(...)` 在 `mountDshA2A` 之后因卸载竞态抛错时，A2A 的 8 条路由与 A2A `DirectoryLease` 永久残留，下一次热重载会静默降级为 `read-only`。改后释放链按确定顺序逐步容错：注销路由/工具/预设/监听器/timer 并复位两个宿主引用 → `closeA2A` → `nativeSessions.dispose()` → `adapter.dispose()` → 诊断 `DirectoryLease` → 服务租约；回滚场景保留原始启动错误，正常卸载场景抛出收集到的错误。
- `packages/dsh-plugin/src/a2a.ts` 的 `close` 与挂载失败回滚改为逐步容错：每条路由的注销单独 `try/catch`，无论路由注销是否抛错都必定执行 `await server.close()` 释放 A2A 存储租约，最后再抛出收集到的异常。改前一条路由的注销抛错会跳过其余路由注销与 `server.close()`，A2A `DirectoryLease` 泄漏。
