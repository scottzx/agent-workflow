# 2026-11-18

## 新增

- 会话归档改为手动 CLI 命令 `acp-service dsh archive`，不再作为 DSH 插件的常驻能力。命令按 `--days`（默认 7）归档静默 DSH 会话，支持 `--dry-run`、`--include-pinned`、`--stop-activity`、`--json`。核心逻辑在 `packages/service/src/dsh-archive.ts`（纯函数，可测），DSH Host 客户端在 `src/dsh-host-client.ts`，会话文件 mtime 读取在 `src/dsh-session-files.ts`，注册表文档读取与陈旧检测在 `src/dsh-registry-file.ts`；CLI 入口 `bin/dsh.ts`。静默口径与之前一致：取 DSH 自身活动记录与会话持久化文件 mtime 中较晚者。**置顶会话默认跳过**，需显式 `--include-pinned`；已归档与运行中的会话也会跳过。新增 `packages/service/test/dsh-archive.test.ts` 14 项通过。**插件侧已移除**：`packages/dsh-plugin/src/auto-archive.ts`、对应测试、`autoArchive` 配置与 `timer` 注入全部删除，`packages/dsh-plugin` 48 项测试（44 通过、4 跳过）通过。
- 内置 ACP Agent `codebuddy`，启动命令为 `codebuddy --acp`，对应 npm 包 `@tencent-ai/codebuddy-code`。定位与 `grok-build` 相同：已安装且本机 CLI 已登录时，可由运行时、`/agents` 目录和 DSH 的 `oneagents-acp-codebuddy` 预设直接拉起。acpx 不发起 CodeBuddy 登录，也不读取它的 API key；未在终端完成登录时，会话会按该 CLI 自己的认证失败。

## 修复

- 随归档改造成 CLI，原先定时器注册即被释放的缺陷连同整个常驻实现一起移除；该缺陷由本机隔离 profile 的端到端探查发现，修复方案不再随插件保留。
- 网关服务 CPU 死循环空转与高频写盘修复（`packages/service/src/a2a/gateway.ts`）：
  1. 修复状态机死循环：`reconcile` 循环此前每 3 秒将已终态（`completed`/`failed`/`canceled`）的 `reportReviews` 重复推进到 `advanceReport`，触发重复账本写入异常并在 `catch` 块内频繁调用 `this.save()` 同步写盘；现已阻断已终态 review 的重复推进。
  2. 修复撤销循环高频刷盘：`reconcileCancellation` 原逻辑每次无条件更新已处于 `blocked` 状态任务的 `checkedAt` 并刷盘，现改为仅在 status 或 targets 发生实质变化时保存。
  3. 增加 7 天默认冷状态自动归档：网关自动将超过 7 天未更新且已进入终态的历史任务与通知归档至 `gateway-archive.json`，大幅降低主存储 `gateway.json` 的体积与序列化开销，并提供 `findArchivedJob` 兼容回查。
  4. DreamMate 汇报日志抑制：为网络注册汇报增加基于错误原因的去重抑制机制，避免未运行状态下每 15 秒高频狂刷相同错误日志。
  5. 发布版本更新至 `0.10.11`。
- `@1agents/dsh-a2a` 在配置端口已被占用时不再把 `EADDRINUSE` 抛成插件启动失败。从该端口起向后最多试 32 个端口，在第一个空闲端口监听；`publicUrl` 若指向被占用的端口，agent card 改为实际地址。其它监听错误仍失败，且失败发生在取得 A2A 存储之前。版本改为 `0.2.6`，尚未发布。本机 `127.0.0.1:3080` 现由 `dsh web --host 127.0.0.1 --port 3080` 持有，桌面 profile 的 `oneagents-dsh-a2a` 仍配置同一地址，因此会走到这条退步。

## 桌面端会话归档

- 对本机正在运行的桌面端 DSH（`desktop` profile，监听 `127.0.0.1:51971`）手动执行了一次超过 7 天的会话归档。通过该进程自己的 Typert RPC（`/api/workspace/archiveSession`）调用宿主权威的 `workspaceRegistry`，归档写进运行中的宿主状态与 `~/.dsh/storages/workspace.json`，没有重启应用，也没有直接改写存储文件。
- 结果：归档集从 182 增至 **665**，本次归档 **483** 个会话，**0 失败**（约 101 秒）。复算后 7 天以上的剩余候选为 0。
- 判定口径与插件一致：最后活跃时间取 DSH 自身活动记录（创建时间或最后一条真实用户消息）与会话持久化文件 mtime 中较晚者，因此冷会话若近期仍写过日志则不算静默。
- 置顶会话按约定豁免。本次两个置顶会话分别为 0.1 天和 1.1 天前，本来就不在 7 天候选内，因此置顶豁免未实际生效；两个置顶会话归档后仍在置顶集合中，未被取消置顶。
- 归档前核对：候选中没有正在运行的会话；84 个「父会话是候选」的子会话本身也都超过 7 天且未运行；没有任何候选是近期会话的父会话；执行本轮的那个会话不在候选内。
- 归档是可逆的：抽测一个会话 `unarchiveSession` 后归档集降为 664、该会话移出归档集，再 `archiveSession` 后回到 665。归档只隐藏会话，不删除日志文件。
- 说明：这是一次性手动归档，不是自动归档的启用。桌面 profile 的 `oneagents-acp` 插件行仍无 `autoArchive` 配置，插件行为与发布前一致。
