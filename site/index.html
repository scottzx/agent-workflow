01 / BUILT AROUND THE AGENT

接入你的系统，
保留 Agent 的原生能力。

从一次命令调用，到应用中的持续会话，
让协议负责连接，让 Agent 继续负责工作。

↻01 — SESSION

会话可以接着做

保留原生 Agent、工作区与会话身份。重连时恢复同一会话，持续处理多轮任务；在 DSH 中回放托管回合的更新。

⌘02 — CAPABILITIES

原生模型与工具

使用 Agent 实际提供的模型、推理设置、模式和命令。在 DSH 中处理权限请求，工具仍由原生 Agent 执行。

⇄03 — INTEGRATION

从本机接入工作流

用 CLI 运行任务，用 SDK 嵌入应用，或通过 HTTP 与 WebSocket 建立连接。需要跨 Agent 委派时，再按需开启 A2A。

02 / NATIVE IN YOUR WORKSPACE

在熟悉的工作台，
继续原生会话。

通过 DeepSeek Harness 插件，选择已发现的 ACP Agent 与本地工作区，直接使用它的模型选项、原生命令和权限交互。

03 / GET STARTED

一个安装入口。
从你需要的方式开始。

正式分发包 @1agents/acp-service 包含运行时、CLI、服务与 DSH 插件。

开始前

安装 Node.js 22.13 或更新版本，并在运行主机上准备好原生 Agent CLI、登录凭据及对应的 ACP 适配器。

安装 DSH 插件后，重启 DSH 并确认插件已启用。插件可自动启动或复用本地 ACP 服务。

完整安装与配置文档 ↗
TERMINAL 
# 安装到 DSH 的 web profile
dsh plugin --profile web add @1agents/acp-service
接下来

重启 DSH → 启用插件 → 新建 ACP · Agent 会话 → 选择现有工作区。

TERMINAL 
# 安装统一 CLI
npm install -g @1agents/acp-service

# 创建并使用 Codex 会话
acp-service codex sessions new
acp-service codex "梳理当前项目结构"
独立使用

不依赖 DSH。进入你的项目目录后运行，Agent 使用本机的工具与登录凭据。

JAVASCRIPT · NODE.JS 
// 先安装：npm install @1agents/acp-service
import { serveAcpService } from "@1agents/acp-service";

const service = await serveAcpService({
  host: "127.0.0.1",
  port: 36812,
  report: false,
});

// 结束时：await service.close();
嵌入应用

通过 HTTP / WebSocket 提供 ACP 服务。另有 /runtime 与 /flows 导出供应用集成。
