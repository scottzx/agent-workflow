01 / BUILT AROUND THE AGENT

Plug into your system.
Keep the Agent's own capabilities.

From one command to a session that stays open inside your app,
the protocol connects, and the Agent keeps doing the work.

↻01 — SESSION

Pick the session back up

Keep the native Agent, workspace, and session identity. Reconnecting restores the same session for more turns, and DSH can replay updates from a hosted turn.

⌘02 — CAPABILITIES

Native models and tools

Use the models, reasoning settings, modes, and commands the Agent actually exposes. Answer permission requests in DSH. The native Agent still runs the tools.

⇄03 — INTEGRATION

Connect from this machine

Run work with the CLI, embed the SDK, or connect over HTTP and WebSocket. Turn on A2A only when you need to delegate across Agents.

02 / NATIVE IN YOUR WORKSPACE

Stay in the workspace you know.
Continue the native session.

With the DeepSeek Harness plugin, pick a discovered ACP Agent and a local workspace, then use its model options, native commands, and permission prompts directly.

Read the DSH guide ↗

↳ You can also run the CLI, SDK, and service on their own and connect your own application.

The available models and controls depend on the Agent, adapter, and account. The DSH plugin currently accepts text prompts.

03 / GET STARTED

One install.
Start the way you need.

The published package @1agents/acp-service includes the runtime, CLI, service, and DSH plugin.

Before you start

Install Node.js 22.13 or newer, and have the native Agent CLI, its credentials, and the matching ACP adapter available on the host that will run it.

After installing the DSH plugin, restart DSH and confirm the plugin is enabled. The plugin starts or reuses its local ACP service.

Full install and configuration guide ↗
TERMINAL 
# Install into the DSH web profile
dsh plugin --profile web add @1agents/acp-service
Next

Restart DSH → enable the plugin → create an ACP · Agent session → choose an existing workspace.

TERMINAL 
# Install the unified CLI
npm install -g @1agents/acp-service

# Create and use a Codex session
acp-service codex sessions new
acp-service codex "Map the current project structure"
Standalone

DSH is not required. Run it from your project directory. The Agent uses the tools and credentials on this machine.

JAVASCRIPT · NODE.JS 
// Install first: npm install @1agents/acp-service
import { serveAcpService } from "@1agents/acp-service";

const service = await serveAcpService({
  host: "127.0.0.1",
  port: 36812,
  report: false,
});

// When finished: await service.close();
Embed

Serve ACP over HTTP / WebSocket. /runtime and /flows exports are also available for application integration.
